Inventory of the project's real assets — what exists, what it's for, where it's used. Consult it
before scanning the asset tree, keep it current as assets change, group by the types that fit.
Real means made or imported for this project — never engine/framework defaults, generated or
package files (e.g. Unity's stock settings, `.meta`, `Packages/`, build output). `Used in` is
mandatory: every scene, component or page that references it, `unused` where nothing does.
